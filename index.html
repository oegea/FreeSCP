Get started

Connected in three steps.

No installer, no account, nothing to configure first.

Download

Grab the build for your computer. On macOS unzip it and drag FreeSCP to Applications; on Linux make the AppImage executable with chmod +x.

Log in

Pick the protocol — SFTP, SCP, FTP, WebDAV or S3 — and enter host, user and password, or choose your SSH key. Your OpenSSH keys work as they are.

Transfer

Your files on the left, the server on the right. Drag between panels or press F5 to copy. Edit remote files in place; they upload when you save.

How it works

Same engine.
Zero emulation.

WinSCP has been a fantastic, free tool on Windows for many years — but it never existed on macOS or Linux, and nothing else quite replaces it. FreeSCP closes that gap: it runs WinSCP's own protocol engine, recompiled natively, behind a Qt rebuild of its interface. So transfers behave exactly like WinSCP, on your Mac.

It's free software under the GPLv3, a project started by Oriol Egea, made possible by leaning on AI for the heavy lifting of the port.

FAQ

Good questions.

Is this the real WinSCP?

It runs WinSCP's real protocol engine — the same open-source code, recompiled for macOS and Linux — behind an interface rebuilt in Qt. It is an independent community port, not made or endorsed by the WinSCP team. On Windows, use the original WinSCP.

Is it really free? What's the catch?

There isn't one. It is GPLv3 open-source software with no paid version, no ads and no account. If you want to support the work you can buy me a coffee, but nothing is locked behind it.

Does it collect any data?

No. FreeSCP has no telemetry, analytics or crash reporting and does not check for updates on its own. The only network connections it makes are to the servers you tell it to connect to. Settings and cached host keys stay on your computer.

Which Macs are supported?

Any Mac running macOS 12 Monterey or newer, Apple Silicon or Intel — it is a single universal app. It is signed with a Developer ID and notarized by Apple, so it opens without security warnings.

The AppImage does not start on my Linux.

Make it executable first (chmod +x FreeSCP-Linux-*.AppImage). AppImages need FUSE 2; if your distro does not ship it, install libfuse2 or run it with --appimage-extract-and-run. It needs glibc 2.35 or newer and an X11 or XWayland session.

Which features of WinSCP are there?

The Commander: dual panels, session tabs, directory tree, SFTP / SCP / FTP(S) / WebDAV / S3, public-key authentication, the transfer queue with parallel connections, remote editing, synchronized browsing, bookmarks, drag & drop. Scripting, the Explorer-style interface and some advanced site settings are not there yet — see the roadmap.

I found a bug or miss a feature.

Please open an issue on GitHub — with the protocol and server type if it is a connection problem. Pull requests are welcome too.
